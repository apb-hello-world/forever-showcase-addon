# Stagekeeper artwork provenance

The 0.2.1 gold title uses StagekeeperWordmark.png; see WORDMARK-PROMPT.md for its
exact prompt, generated source, export measurements and runtime location.

Tool: built-in image generation. Owner-selected reference:
`../mockups/stagekeeper-v1.png` (November 25, 2026). These two assets were produced
from that reference with transparent exteriors. Original PNGs are retained here.
Runtime copies are uncompressed 32-bit TGA, exported with ffmpeg (shell 1024x1024,
button 512x128); Lua restores shell proportions at 1000x760 and three-slices buttons.
Generated artwork review is not native visual verification.

## StagekeeperShell.png prompt

Create the production background texture for the approved Stagekeeper UI reference. Match its original dark walnut wood, oxblood velvet theater curtain corner accents, warm brass rim, central burgundy title plaque and sun crest. Front facing orthographic, approximately 1000:760 aspect ratio. The window itself fills the image edge to edge with only a tiny transparent exterior margin. Transparent exterior, opaque surfaces inside. Remove ALL lettering, ALL icons, ALL buttons, ALL selection highlights, ALL lines of text, ALL bottom concept labels. Retain only the window shell and empty working surfaces. Exactly three columns: dark wood add-on inset from x4% to24%, ivory scene-list inset from x25% to47%, larger ivory detail panel x49% to96%. Body starts y20% and ends y81%; keep quiet completely empty surfaces, no decorative dividers inside panels. Each panel has coherent rounded finished rims, brass on the large detail panel. Header blank title plaque centered x28%-74%, y7%-16%; curtains limited to extreme upper corners. Bottom empty wood action strip y83%-94%, full width, and narrow empty wood footer below. No UI text baked into the art. No close button. Preserve polished artisanal material craft of reference, not flat colors. This is a reusable native game UI texture, not a screenshot or a mockup board.

## StagekeeperButton.png prompt

Generate a single production native fantasy game UI button texture matching the attached approved Stagekeeper reference: aged polished brass double rim, dark oxblood leather/velvet inset, gently clipped rounded rectangular corners. Wide horizontal button 4:1 aspect ratio, straight-on orthographic, no perspective. One button only, centered and fills canvas with tiny transparent exterior margin, opaque deep burgundy quiet center. Rich subtle material texture, precise crisp metal bevels, restrained warm specular edges. Absolutely no text, letters, symbols, icons, or other objects. No glow outside button. This texture will be three-sliced for real live text buttons. Match the reference's Hide controls button styling.
